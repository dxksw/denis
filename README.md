# Сайт-портфолио Дениса Галюкевича

Личный сайт: спорт, статьи, хронология и достижения на пути к экономическому образованию за рубежом.

## Как добавить запись

1. Открой админ-панель: адрес сайта + `/admin/`.
2. Нажми «Sign In with Token» и вставь токен GitHub (как его получить — ниже).
3. Слева выбери раздел, нажми кнопку создания записи, заполни форму и сохрани.
4. Через 1–2 минуты запись появится на сайте.

| Что добавить | Где в админ-панели |
|---|---|
| Запись в хронологию, итог квартала или года | Хронология |
| Статью и перевод на английский | Статьи |
| Достижение с подтверждением | Достижения |
| Забег | Забеги: рекорды, темп и график обновятся сами |
| Навык, соцсети, портрет, тексты «Обо мне» | Страницы и настройки → Обо мне |
| Цели по времени в беге | Страницы и настройки → Спорт — цели |

## Токен для входа

GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token:

- Repository access: Only select repositories → этот репозиторий;
- Permissions → Contents: Read and write;
- срок действия — максимальный. Когда истечёт, создай новый так же.

Токен хранится только в твоём браузере. Никому его не показывай.

## Важно

Репозиторий открытый: всё, что сохранено через админ-панель, включая черновики, видно на GitHub. Не пиши сюда ничего личного.

## Языки

Сайт двуязычный: английская версия открывается по умолчанию, русская — по адресу `/ru/`, переключатель EN / RU есть на каждой странице.
Записи пишутся на русском. Английский текст добавляется в блоке «English version» в форме записи (или его переводит Claude по просьбе).
Пока перевода нет, на английской версии показывается русский текст с пометкой «In Russian» и ссылкой на Google Переводчик.
Тексты меню, заголовков и кнопок на обоих языках — в «Страницы и настройки → Тексты интерфейса».

## Что где лежит

- `content/` — весь контент сайта, его меняет админ-панель;
- `static/` — оформление, шрифты и загруженные картинки;
- `build.mjs` — сборщик сайта, работает без внешних библиотек;
- `ui-defaults.mjs` — тексты интерфейса по умолчанию на двух языках;
- `.github/workflows/deploy.yml` — автоматическая публикация на GitHub Pages.

Контент хранится в обычных файлах, поэтому сайт можно в любой момент перенести на другой хостинг.
